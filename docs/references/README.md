# Referências por stack

Leitura prévia para configurar o repositório de uma empresa. Não são plugins nem
skills do cérebro: são notas pesquisadas, datadas, com fontes. Quando um padrão daqui
doer duas vezes em trabalho real, ele passa pelo `RULER.md` e vira skill ou regra.

| Arquivo | Quando ler |
|---|---|
| [aws.md](aws.md) | empresa em AWS: MCP gerenciado, plugins oficiais, Bedrock, permissões, molde de CLAUDE.md |
| [databricks.md](databricks.md) | empresa em Databricks: skills oficiais, Unity Gateway, DABs, permissões, revisão Spark/Delta |

Convenção: plugins de stack entram em **escopo project** (`--scope project`), nunca
user. O cérebro é seu; a stack é da empresa.
